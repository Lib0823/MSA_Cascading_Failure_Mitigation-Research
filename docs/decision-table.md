## 표

판정 대상은 서비스 v 다. **호출 경로**는 v 가 직접 또는 한 단계 건너 호출하는 하위 서비스다(orders 에게
payment 는 1홉, gateway 에게는 2홉). **풀 대기율**은 HikariCP 의 `pending ÷ (pending + active)` 다. 조치는
엔진과 같은 지점, 곧 v 의 호출자 쪽에 건다.

| # | 관측 | 판정 | 조치 |
|---|---|---|---|
| ① | 호출 경로 p95 ≤ 기준선의 2배, 자기 오류율 ≤ 30% | 정상 | 보류 |
| ② | 호출 경로 p95 ≤ 2배, 자기 오류율 > 30% | S1 DB 커넥션 고갈 | 벌크헤드 |
| ③ | 호출 경로 p95 > 2배, 호출 경로 풀 대기율 ≤ 0.5 | S3 하위 서비스 지연 | 서킷 브레이커 |
| ④ | 호출 경로 p95 > 2배, 호출 경로 풀 대기율 > 0.5 | S1 DB 커넥션 고갈 | 벌크헤드 |
| ⑤ | 증설·CPU 기반 HPA 를 검토할 때 | — | DB 커넥션 예산의 여유를 먼저 본다 |

- **관측 → 판정(①~④)** 은 34 에피소드로 학습한 깊이 2 결정 트리다. 학습값은 2.12배·30%·0.43 이고,
  위 숫자는 아래 주의 3 의 범위 안에서 반올림했다.
- **판정 → 조치** 는 학습한 것이 아니라 비용함수에서 유도한 것이다. S1 에서 보류를 이길 수 있는 조치는
  벌크헤드(θ = 0.46)뿐이고, S3 에서는 CB(θ = 0.00025)뿐이며, 증설은 두 장애 모두 θ = ∞ 다(원고 표 1).
- **⑤ 는 측정값이다.** DB 예산 30 에서 증설하면 처리량이 −53.5%, 예산 70 에서는 +58.2% 였다. CPU 기반 HPA 도
  각각 −25.1%, +59.8% 였다(원고 표 2). 기존 파드가 커넥션을 쥐고 있으면 신규 파드는 커넥션을 얻지 못한다.
  CPU 기반 HPA 는 이 여유를 보지 못한다. 손익이 갈리는 정확한 경계는 예산 두 점으로는 정해지지 않는다.

## 주의 셋

1. **조치를 건 뒤에는 이 표로 다시 판정하지 않는다.** 벌크헤드와 CB 는 payment 앞의 대기열을 줄여 풀
   대기율을 지운다. 폐루프 S1 의 장애 구간에서 payment 풀 대기율(실행별 중앙값)은 무조치(A4)일 때 0.78,
   조치가 나가는 정책(A2·A5·A6)일 때 0.00 이었다. 호출 경로 p95 가 2배를 넘은 S1 표본 중 ④ 로 가는 비율은
   임계 0.5 에서 자연 에피소드 99.5%, 조치를 강제한 셀 51.5% 다. 나머지는 ③ 으로 떨어진다. 그러니 표대로 다시
   판정하면 S1 에 건 벌크헤드가 CB 로 바뀐다. 조치를 유지하는 동안에는 판정을 고정한다. GBM 은 강제 셀로
   조치 뒤의 동역학을 학습해 이 전환에 덜 흔들린다. 폐루프에서 벌크헤드 직후 틱의 S3 오진은 A6 0%(118건),
   A5 17.7%(368건)로, 벌크헤드가 없던 틱(A5 12.5%, 40건)과 크게 다르지 않았다.
2. **①·② 의 "2배" 는 학습해서 얻은 값이 아니다.** 라벨이 "SLO(기준선 2배) 위반" 으로 정의돼 있어, 트리가 그
   정의를 다시 찾아낸 것이다. 라벨에서 상류 조건을 빼면 최종 트리의 위험 분할이 *호출 경로 p95* 에서
   *자기 p95*(2.29배)로 옮겨 간다.
   운영에서는 SLO 경보를 그대로 쓰면 된다. **학습해서 얻은 것은 ③·④ 를 가르는 풀 대기율이다.** 이 분할은
   라벨 정의를 바꿔도 같은 지표, 같은 감도 곡선으로 나온다. H7(최소 관측 집합이 f2 를 포함한다)과도 맞는다.
3. **임계는 넓은 범위에서 결과가 같다.** 풀 대기율 임계를 0.4~0.6 사이 어디에 그어도 자연 에피소드는
   S1 99.5%, S3 100% 가 맞다. 접기마다 다시 학습한 값은 지연 배수 1.5~2.2, 오류율 30~34%, 풀 대기율
   0.11~0.43 이었다. 풀 대기율이 흔들린 것은 주의 1 의 강제 셀 때문으로 보인다 — 강제 셀을 빼고 학습하면
   4접기 중 3개가 0.50 을 고른다.

## 얼마나 맞는가

GroupKFold 4접기의 접기 밖 평가다(34 에피소드, 10,886 표본, Δ = 30초). GBM 경로는 원고 §5.4 의 수치를 그대로
재현했다(장애 없는 구간 정상 표본 4,821건 중 35.2% 에 개입). *자연* 은 조치를 강제하지 않은 에피소드(무조치
셀 포함), *강제* 는 장애와 함께 벌크헤드·CB 를 강제한 셀이다.

| | 자연 (6,275) GBM | 자연 **결정표** | 강제 (4,611) GBM | 강제 결정표 |
|---|---|---|---|---|
| 3클래스 macro F1 | 0.833 | **0.859** | 0.764 | 0.631 |
| 병목 유형(ŝ) 정확도 | 85.3% | **92.4%** | 74.5% | 61.6% |
| S1 → 벌크헤드 / 잘못 CB / 보류 | 86.5 / 6.2 / 7.3% | 83.1 / **0.2** / 16.7% | 62.4 / 22.7 / 14.9% | 30.7 / 42.7 / 26.6% |
| S3 → CB / 잘못 벌크헤드 | 74.9 / 19.6% | **83.4 / 7.8%** | 66.7 / 15.8% | 73.8 / 16.3% |

전체에서는 결정표 0.754, GBM 0.803 이고, 판정이 일치한 비율은 90.8% 다. 장애 없는 구간의 개입률은 GBM 35.2%
(거의 전부 CB 장전), 결정표 0.0% 다. CB 장전은 표본당 비용이 0.0002 라 비용 차이는 작다.

**조치를 걸기 전, 즉 첫 판정을 내리는 상태에서는 특징 셋짜리 표가 174차원 GBM 보다 낫다.** GBM 이 앞서는
것은 두 가지다.
- **조기 경보** — 자연 에피소드의 S1 을 보류한 비율이 GBM 7.3%, 결정표 16.7% 다. 지연이 2배를 넘기 전에
  잡아내는 몫이다.
- **조치 뒤의 판정** — 위 표의 *강제* 열이다.
