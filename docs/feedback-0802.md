신뢰도 기반 GNN을 활용한 MSA 연쇄 장애 선제 대응 아키텍처 보완 전략
본 보고서는 Lib0823 연구자의 학위 논문 심사 방어 및 실험 설계를 돕기 위해, 선행 연구(GRAF, FIRM, AGQ, GraphGRU) 분석 결과와 시스템 엔지니어링 측면의 최적화 방안을 종합하여 작성되었습니다.
1. 앙상블 모델(N=5)의 추론 오버헤드 증명 및 실시간성 확보
[문제 정의] Deep Ensemble(N=5) 기반의 추론이 MSA의 짧은 장애 골든타임 내에 완료될 수 있는지에 대한 의구심.
학술적 증명:
선행 연구인 FIRM은 1.2ms의 추론 속도를 달성했으며
, AGQ는 추론 및 스케줄링에 0.4s가 소요됨을 보고했습니다
.
본 연구의 목표는 GRAF 아키텍처가 제안한 전체 최적화 결정 시간(약 6.7초)
보다 현저히 빠른 지연 시간 내에 5개 모델의 통합 추론을 완료하는 것입니다.
대응 전략:
병렬 추론(Parallel Processing): 5개의 GAT 모델을 독립적인 프로세스에서 병렬로 구동하여 전체 지연 시간을 단일 모델 추론 시간 수준으로 억제합니다.
가속 엔진: 추론 지연이 발생할 경우 TensorRT나 ONNX Runtime과 같은 최적화 엔진을 도입하여 실시간 응답성(Target: 100ms 이내)을 보장합니다.
2. 'Read Redirection' 조치의 비침습적 구현
[문제 정의] 애플리케이션 코드 수정 없이 인프라 계층(Istio)에서 '읽기 트래픽 리다이렉션'을 자동화할 수 있는가?
학술적 증명:
Online Boutique 벤치마크 내에서 읽기 부하가 높은 ProductCatalog 서비스를 타겟으로 설정합니다
.
Istio 서비스 메쉬 환경에서 VirtualService와 DestinationRule 설정을 동적으로 변경하여 트래픽의 일부를 읽기 전용 복제본(Read-replica)으로 분산하는 시나리오를 입증합니다
.
대응 전략:
가중치 기반 라우팅(Weight-based Routing): Envoy Proxy의 사이드카 패턴을 활용하여, 예측 신뢰도가 중간 구간일 때 가역적 조치인 트래픽 분산을 트리거함으로써 시스템 가용성을 확보합니다.
3. 신뢰도(Confidence) 지표의 정확성 및 Safety Guard 설계
[문제 정의] AI 모델이 산출한 신뢰도 수치를 시스템 제어 루프의 근거로 삼기에 타당한가?
학술적 증명:
ECE(Expected Calibration Error): 모델의 확신 정도와 실제 정답률 사이의 일치도를 정량적으로 평가하여 신뢰도 지표의 타당성을 입증합니다.
오탐(False Positive) 분석: 신뢰도 인지 정책을 적용했을 때, 불필요한 Traffic Shedding으로 인해 **정상 요청이 차단되는 비율(Drop Rate)**이 기존 방식 대비 얼마나 감소하는지 비교 제시합니다.
대응 전략:
분산 기반 불확실성: 앙상블 결과값 사이의 분산(Variance)을 신뢰도의 역척도로 사용합니다. 분산이 임계치 이상일 경우 '저신뢰도'로 판단하여 극단적 조치를 유보하는 Safety Guard를 아키텍처에 구현합니다.
4. 정적 그래프(Static GAT) 활용의 타당성 논거
[문제 정의] MSA의 동적인 인스턴스 변화 환경에서 정적인 호출 위상(Topology) 정보가 유효한가?
학술적 증명:
논리적 위상의 안정성: GRAF와 FIRM에서 입증되었듯, 물리적 Pod는 수시로 변하지만 서비스 간의 '논리적 호출 관계'는 서비스 업데이트 전까지 매우 안정적입니다
.
상태 인지: AGQ가 시도한 것처럼, 노드 특징(Node Feature)에 실시간 리소스 데이터를 주입함으로써 고정된 위상 위에서 동적인 상태 변화를 충분히 포착할 수 있습니다
.
대응 전략:
서비스 추가/삭제와 같은 대규모 변경 시에는 FIRM에서 제안한 전이 학습(Transfer Learning) 기법을 사용하여 전체 모델 재학습 없이 신규 위상에 빠르게 적응하도록 설계합니다
.
5. (Deep-Dive) TA-GAT 전략: 시공간성 확보를 위한 데이터 공학
[문제 정의] STGAT와 같은 복잡한 모델을 쓰지 않고도 어떻게 장애의 시공간적 전파 패턴을 학습할 수 있는가?
설계 근거 (The 'Why'):
AGQ나 GraphGRU와 같은 복잡한 시공간 레이어는 계산량이 많아 5개 모델 앙상블 시 추론 오버헤드를 유발하여 '선제적 대응'의 타이밍을 놓칠 위험이 큽니다
.
따라서 모델 구조는 가벼운 표준 GAT를 유지하면서도, 입력 데이터 레벨에서 시계열성을 강화하는 것이 시스템 아키텍처 연구로서 더 성숙한 접근입니다.
핵심 방법론: TA-GAT (Temporal-Augmented GAT):
Sliding-Window 특징 압축: 노드 특징 벡터(x

 )에 현재 시점 데이터뿐만 아니라, 최근 윈도우(예: 최근 5분) 동안의 통계량을 압축하여 주입합니다.
구성 예시: [현재 부하, 최근 1분 평균, 부하 변화율(Slope), 표준편차, 직전 SLO 위반 여부]
논리적 방어: 이를 통해 모델은 구조적으로는 정적 그래프를 처리하지만, 실제로는 **부하의 시간적 추세(Temporal Trend)**와 **위상적 전파 경로(Spatial Path)**를 동시에 학습하게 됩니다. 이는 추론 속도를 최적화하면서도 기능적으로 STGNN의 효과를 내는 엔지니어링적 최적화 전략입니다.
교수 총평 (심사 방어 논리)
"본 연구는 단순한 AI 모델 개선이 아닌, **실제 운영 환경의 제약(지연 시간, 신뢰성)**을 고려한 시스템 아키텍처 연구입니다. STGAT와 같은 무거운 모델을 배제하고 TA-GAT 방식을 택한 것은 실시간 시스템의 반응성을 보장하고 앙상블 모델의 신뢰도를 확보하기 위한 **의도된 설계(Design Choice)**입니다. 이를 통해 KAIST GRAF의 위상 인지 능력과 FIRM의 신뢰성 높은 제어를 결합한 완성도 높은 아키텍처를 제안합니다."
