## §3 제안 방법 (1.0p) — 핵심

### 구조

```
3-1  전체 구조          예측 → 의사결정 → 실행 3계층        (그림 1)
3-2  예측 계층          3단 사다리 + 왜 GBM 인가 (H7)
3-3  의사결정 계층      비용함수 → θₐ 유도                 ← 핵심 기여
3-4  실행 계층          조치 4종 + 적용 지점                (표)
```

### 3-2 예측 계층

- **3단 사다리** — ① 규칙/임계값(위상 없음) → ② GBM + 이웃 집계(주력) → ③ GAT(검증 대상). [proposal.md:793](../proposal.md)
  - ①→② = 위상 정보 자체의 기여 / ②→③ = 표현 학습의 기여
  - **통제 원칙**: 세 단계에 동일한 시계열 feature 를 준다. 그래야 유일한 변수가 위상 정보가 된다
- **의미 기준 공통 슬롯 6종** (f1~f6) — [buildDataset.py](../../code/model/buildDataset.py) docstring
  - ⚠️ `f5`(자원 사용률)는 Compose 에서 결손이다. **빼지 않고 0 으로 채운 사실을 쓴다** — 조용히 빼면 ①②③ 의 입력이 달라져 비교가 오염된다
- **불확실성** — 앙상블 N=5, `p_eff = max(0, p̄ − κ√u)`

### 🔴 "왜 GBM 인가" — 여기가 H7 이 들어가는 자리

성능이 아니라 **feature 중요도로 최소 관측 집합을 뽑을 수 있어서**다. 이 문장을
쓸 수 없어서 막혀 있었고, 이제 숫자가 있다 ([proposal.md §4-4](../proposal.md)).

| 과제 | 전체 5종 | **f2+f4** |
|---|---|---|
| 3클래스 | 0.908 ± 0.083 | 0.892 ± 0.092 |
| S1 vs S3 | 0.927 ± 0.052 | **0.937 ± 0.041** |

표준 지표(지연 p95 + 에러율) 0.647 → 풀 획득 대기 추가 **0.930 (+0.284, +30.6%)**.

**`f4`(지연 p95)가 최소 집합에 든 조건을 함께 써야 한다** — `f4` 는 기준선의 4배에서
포화되므로, 극단 강도만 모으면 S3 표본의 78.8% 가 상한에 붙어 정보가 버려진다.
중간 강도를 섞어야 등급 있는 구분자가 된다([challenges.md](../../research/challenges.md) J17).
**관측 설계 처방의 일부**이므로 빼지 않는다.

**GAT 를 주력에서 내린 근거도 같은 자리에 쓴다** — 해석 가능성이 산출물의
조건이기 때문이다.

### 3-3 의사결정 계층 — 논문의 중심

[proposal.md:269](../proposal.md)

```
E[비용 | 조치 a] = p·[ (1−mₐ)·L + Dₐ ] + (1−p)·[ Dₐ·Rₐ ]
E[비용 | 보류   ] = p·L
```

`E[비용|a] < p·L` 을 p 에 대해 정리하면 조치별 임계값이 **유도**된다.

```
θₐ = Dₐ·Rₐ / ( mₐ·L − Dₐ·(1−Rₐ) )
```

**반드시 쓸 것 세 가지** — 이것이 기여의 실체다.

1. **임계값을 손으로 긋지 않는다.** 신뢰도 구간을 저자가 정하는 것이 아니라 비용 구조에서 나온다
2. **분모 ≤ 0 이면 θ = ∞ → 그 조치는 자동 배제된다.** 완화효과가 부작용을 못 넘으면 수식이 스스로 뺀다. **H4 가 가정이 아니라 수식의 결과**라는 점
3. **`Dₐ` 가 H5a 와 같은 양이다.** 즉시 비용(정상 트래픽 손실) = 오탐 비용. 따라서 `mₐ` 실험의 정상 구간이 `Dₐ` 를 측정한다 — 별도 실험이 필요 없다
   - 실측 `Dₐ(Bulkhead) = 0.716` (가정값 0.25 의 **2.9배**). **두 방법이 독립으로 일치했다** — A5 의 선택에서 잰 0.703 과 조치를 강제해 잰 0.716
   - 가정값으로는 `θ_Bulkhead = 0.043` 이 나와 **장애가 없는 구간에서도 2/3 을 조치**했다. **도입 가능성이 엔진의 성질이 아니라 캘리브레이션의 결과**라는 것이 요점

> `κ` 와 `Rₐ` 는 **측정 대상이 아니라 정책 파라미터**다. 민감도 분석으로 보고한다
> (사용 가능 구간 `Rₐ ∈ [0.12, 0.20]`, `θ ∈ [0.47, 0.59]`). 실측값인 척 쓰지 않는다.

### 🔴 유도된 `θ` 가 현업 관행을 재현한다 (2026-11-01, 2026-11-02 분할)

⚠️ **2026-11-02 개정.** 이 절은 처음 *"`3-3` 에 네 번째 논점을 추가한다"* 로
썼으나, `§3` 이 **1.0p** 로 줄면서 통째로 들어갈 수 없다. 그리고 들여다보니
**성격이 다른 두 개가 섞여 있다.**

| 내용 | 가는 곳 | 왜 |
|---|---|---|
| 실측 `Dₐ` 표 + 유도된 `θ` | **§5 결과** | 측정값이다 |
| "비용함수가 관행을 재현했다" | **§5 결과** | 발견이다 — `§3` 에서 말하면 주장이고 `§5` 에서 말하면 결과다 |
| CB 가 왜 0 인가(`failureRateThreshold`) | **§5 결과** | 그 결과의 해설이다 |
| 🔴 **"쪼개도 θ=0 이다"** | **§3 제안에 남긴다 (1문장)** | **모델의 성질이고 반론 차단이다 — 결과가 아니다** |

마지막 한 줄이 `§3` 에 없으면 *"비용 모델이 CB 를 제대로 다루지 못한다"* 는
반론을 `§5` 까지 끌고 가게 된다. 제안을 설명하는 자리에서 막아야 한다.

조치별 `Dₐ` 를 실측한 결과([proposal.md](../proposal.md) §2-B,
[challenges.md](../../research/challenges.md) J19):

| 조치 | 가정 | **실측** | **유도된 θ** | 현업 관행 |
|---|---|---|---|---|
| Bulkhead | 0.25 | **0.716** | θ(S1) **0.460** | **필요할 때 조인다** |
| Circuit Breaker | 0.15 | **0.002** | θ(S3) **≈ 0** | **상시 장전한다** |

**아무도 알려주지 않았는데 비용함수가 이 구분을 재현했다.** *"임계값을 손으로
긋지 않는다"* 의 가장 강한 근거다 — 유도된 값이 실무자 직관과 맞는다.

**왜 CB 가 0 인지 한 문장으로 쓴다**: `failureRateThreshold(50%)` 이므로 **장애가
없으면 회로가 열리지 않는다.** 즉 *"장전하는 비용"* 은 실제로 0 에 가깝고 비용은
**열릴 때** 발생한다.

**그리고 쪼개도 같다는 것을 쓴다** — `Dₐ` 를 장애 시 `D_f` / 정상 시 `D_n` 으로
나누면 `θₐ = D_n·Rₐ / (mₐL − D_f + D_n·Rₐ)` 이고 `D_n ≈ 0` 이면 **θ 는 여전히 0**
이다. **모델의 결함이 아니라 올바른 결론**이라는 점이 핵심이다. 이 한 줄이 없으면
*"비용 모델이 CB 를 제대로 다루지 못한다"* 는 반론을 그대로 받는다.

### ⚠️ 그래서 §1 기여 서술의 범위를 좁혀야 한다

🔴 **2026-11-02 재개정 — 이 절의 전제가 틀렸다.**

종전에 *"H2 의 실증 무대는 `θ` 가 중간 구간인 Bulkhead·S1(θ=0.460) 이다"* 라고
적었다. **`θ=0.460` 은 엔진에 없는 값이다.** 실측 `Dₐ`=0.716 을 넣었을 때
유도되는 값이며, [[J18]]·[[J19]] 가 배선을 유보한 바로 그것이다. 엔진은 가정값
`Dₐ`=0.25 로 **θ_BH = 0.0435 · θ_CB = 0.0226** 을 쓴다.

그리고 S1 에서 20셀을 측정한 결과(**[[J22]]**) **그 구간에서도 게이팅이 실증되지
않았다** — A5 는 5회 중 2회만 참았고 중앙값은 0 이다. 두 `θ` 가 `p_eff` 의
`p50`(0.063) 보다도 작아 **게이트가 상시 열려 있었다.**

**따라서 기여 서술을 이렇게 좁힌다.**

| 종전 | 개정 |
|---|---|
| ~~*"게이팅이 유효한 구간은 θ 가 중간인 조치이며, 그 구간이 존재함을 보인다"*~~ | *"**`θ` 를 비용 파라미터로부터 유도하는 절차**를 제시하고, **게이팅이 작동할 조건**(`θ` 가 `p_eff` 분포와 같은 규모)을 실측으로 규명한다"* |

**조건의 규명은 음성 결과가 아니다.** *"줄였다"* 는 아직 쓸 수 없지만, *"어떤
조건에서 줄어드는가"* 는 측정으로 답했고 **그 답이 다음 실험을 지정한다**(실측
`Dₐ` 배선). 넓게 주장한 뒤 심사자가 수치를 들여다보면 방어가 어렵지만, 이렇게
쓰면 반론이 들어올 자리가 없다.

⚠️ **종전 본문의 *"실측: A5 보류 4.8% vs A6 0%"* 는 S3·64워커 2회 측정이다.**
S1·32워커 5회에서는 A5 `[0 0 0 3 4]%` · A6 `[0 0 0 0 0]%` 였다. **반복이 늘자
중앙값이 0 으로 내려갔다** — 2회 측정의 4.8% 를 대표값으로 쓰면 안 된다.

### Brownout 은 §3-3 에서 민감도 파라미터로 다룬다

`Dₐ(Brownout)` 는 **처리량으로 측정하지 않는다.** Brownout 은 선택 호출을
생략하므로 처리량이 오히려 **늘어난다** — 지표가 비용의 반대 방향이다. 비용은
품질 저하이므로 `D_downgrade` 와 같이 **운영자 정책 파라미터 + 민감도 분석**으로
처리한다(§2-B). `Rₐ` 와 같은 지위다.

**이것도 쓸 거리다** — *"측정할 수 있는 것과 선언해야 하는 것을 구분했다"* 는
서술은 파라미터를 뭉개지 않았다는 증거가 된다.

#### 왜 "현업 관행 재현" 은 §5 이고 "쪼개도 같다" 는 §3 인가

분량 때문만이 아니다. **그 논점은 제안의 내용이 아니라 제안의 검증이다.**
측정한 `Dₐ` 와 `mₐ` 만으로 유도한 `θ` 가 *"CB 는 상시 투입, Bulkhead 는 선별
튜닝"* 이라는 관행을 재현한다는 것은, 비용함수가 현실을 맞게 모델링했다는
**증거**다. `§3` 에서 말하면 주장이고, `§5` 에서 말하면 결과다.

그리고 거기서 분량이 나온다 — `§5` 는 0.7p 이고 실측값 표가 이미 들어간다.

**반대로 "쪼개도 같다" 는 측정이 아니다.** `θₐ = D_n·Rₐ / (mₐL − D_f + D_n·Rₐ)`
는 비용함수를 다시 미분해서 얻는 **대수적 결과**이며, 어떤 실험도 그것을 바꾸지
못한다. 그래서 그것은 제안의 성질이고 `§3` 에 속한다.

그리고 `§3` 에 있어야 **작동한다.** 독자가 `θ_CB ≈ 0` 을 `§5` 에서 처음 보면
*"그럼 모델이 CB 를 못 다루는 것"* 이라고 읽는다. `§3` 에서 **쪼개도 0 이라는
것을 미리 말해 두면** 같은 숫자가 `§5` 에서 *"예상된 결론"* 으로 읽힌다.
**같은 값이 결함에서 예측으로 바뀐다 — 순서 하나로.**

**측정 결과 ① 이 성립하지 않아 순서를 바꾼다.**

1. **유도된 `θ` 가 타당한가** (표 1) — **이제 이것이 주 결과다.** 측정한 `Dₐ`·`mₐ`
   만으로 유도한 `θ` 가 *"CB 는 상시 장전, Bulkhead 는 선별 튜닝"* 이라는 관행을
   재현한다. 비용함수가 현실을 맞게 모델링했다는 증거이며, **실험의 음성 결과와
   무관하게 성립한다.**
2. **개입에는 비용만 남는가** (표 2) — `mₐ` 가 실현되지 않는 환경에서 성능이
   **개입 빈도의 역순**이 된다. 이것은 제안의 승리가 아니라 **조치 선택이 왜
   필요한지의 증거**다. 아무 조치나 걸면 손해라는 뜻이기 때문이다.
3. 🔴 **게이팅이 오탐 개입을 줄이는가** (표 3·4) — **줄인다. 단 측정은 반사실로
   한다.** 같은 결정 레코드에 `p̄`·`p_eff` 를 대입하면 **+2.9%p**(게이트가 실제로
   걸리는 S1 판정 기준 **+9.1%p**)이고 **5회 반복 산포가 0** 이다. **A6 을 별도
   실행으로 두는 비교는 쓰지 않는다** — 폐루프에서 위험도 분포가 내생적이라
   `κ` 가 분리되지 않는다([[J24]]). 그리고 **`θ ≈ 0` 인 조치의 비중만큼 효과가
   희석된다**(이번엔 S3 판정 68%)는 **작동 조건**을 함께 쓴다.
4. **A2(규칙) 대비** — A2 가 A5 보다 goodput 이 높고(187.6 vs 184.7) **산포도
   훨씬 작다**(1.4 vs 13.2). 숨기지 않고 쓴다. 이 환경에서 A2 가 유리한 이유는
   **덜 개입하기 때문**(36% vs ~100%)이며 ②와 같은 설명으로 닫힌다.

⚠️ **분량 재확인**: 표 셋 + 해석 네 단락은 `0.7p` 를 넘는다. **표 3 을 본문
서술로 녹이거나**(θ 두 값과 `p_eff` p50 만 문장으로), 표 1 을 `§3` 의 수식
설명에 흡수시킨다. 집필 시 결정한다.
